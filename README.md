# Data-Analytics-Portfolio
Repo for my data analytics projects 

This is where I will be creating all of the projects for my data analytics porfolio 

The first project will be around the TikTok Creator Where's My Gate and their content performance

What Drives Growth And Engagement On A Travel TikTok Account

The goal of this project is to identify trends in key metrics including views, likes, comments shares and followers gained

The data has been taken directly from TikToks Analytics Site 

The Final Deliverables will be a dashboard presenting content performance, documentation around the analysis conducted and actionable recommendations to reach targets 

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
I have broken down the project into answering 5 key questions:

  What Content Performs The Best?
  
  When Should Videos Be Published?
  
  What Drives Engagement?
  
  What Drives Follower Growth?
  
  Does Video Length Impact Performance?
